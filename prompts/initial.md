## 6. ANIMATION AND SMOOTH MOTION

Use motion to improve the experience, not distract from the content.

Preferred tools:
- Framer Motion if using React
- Motion for React if using its current supported package
- CSS transitions and keyframes for lightweight effects

Implement:

1. Hero entrance animation
   - Gentle fade-in
   - Slight upward movement
   - Staggered headline and CTA appearance

2. Vehicle image reveal
   - Subtle opacity or clip-path reveal
   - Avoid excessive parallax or scaling that crops the vehicle

3. Scroll-triggered section reveals
   - Small vertical movement
   - Short staggered delays for card groups
   - Trigger once where appropriate

4. Navigation
   - Smooth menu opening and closing
   - Subtle background change when scrolling

5. Service cards
   - Small hover lift on devices that support hover
   - Clear focus states for keyboard users

6. Buttons
   - Smooth colour transitions
   - Subtle hover or press feedback

7. FAQ
   - Smooth accordion expansion without excessive delay

Motion rules:
- Keep animations subtle and premium.
- Prefer short, responsive transitions.
- Avoid long loading animations.
- Do not delay access to the main content.
- Avoid continuous decorative animation.
- Avoid heavy scroll-jacking.
- Avoid large-scale parallax on mobile.
- Respect `prefers-reduced-motion: reduce`.
- Do not animate essential content in a way that hides it from search engines or assistive technologies.
- Avoid layout shifts caused by animated dimensions.
- Do not sacrifice performance for visual effects.

The site should feel smooth on mid-range Android devices, not only on high-end desktops.
